# Creador de mensajes de recaudación de fondos CPI

## Description

Genera y evalúa mensajes de campañas alineados con la Guía de Comunicaciones del CPI | Creates and evaluates campaign messages aligned with the CPI Fundraising Communications Guide.

## Overview

This custom GPT helps the Centro de Periodismo Investigativo (CPI) create and refine fundraising campaign messages, emails, and calls to action that align with their institutional communications standards. It can both generate new fundraising content for campaigns and events (like donation matching programs) and evaluate existing messages to ensure they maintain CPI's commitment to transparency, journalistic independence, and community connection while using an appropriate institutional tone.

This custom GPT was created by **Annette Ramirez**.

## Setup Instructions

1. In ChatGPT, [create a new GPT](https://chatgpt.com/gpts/editor).
2. Give it the name and description above.
3. Copy the contents of `INSTRUCTIONS.txt` into the instruction window.
4. Edit the instructions to fit your organization and mission.
5. Set the model to **No Recommended Model**
6. Enable the capabilities listed above
7. Upload your organization's Communications Guide to the knowledge files. See the [knowledge folder](./knowledge) for more details.
