# CPI Fundraising GPTs

A collection of custom GPT assistants created for the [Centro de Periodismo Investigativo](https://periodismoinvestigativo.com/) (CPI) newsroom in Puerto Rico to support fundraising, translation, and donor communication workflows.

**Created by:** Annette Ramirez  
**Program:** AJP AI Revenue Program (2025)

## Overview

These three specialized GPTs were developed as part of CPI's AI integration initiative to streamline fundraising operations, enable bilingual content publishing, and enhance donor engagement. The tools leverage CPI's Communications Guide and style preferences to maintain institutional voice and messaging standards.

## GPTs Included

1. **[CPI Funder Narrative Assistant](./CPI%20Funder%20Narrative%20Assistant/)** - Generates and refines grant proposals, cover letters, and fundraising narratives tailored to specific funder priorities
2. **[Creador de mensajes de recaudación de fondos CPI](./Creador%20de%20mensajes%20de%20recaudacion%20de%20fondos%20CPI/)** - Creates and evaluates Spanish fundraising campaign messages aligned with CPI's communications standards
3. **[Revenue CTA Messaging Translator](./Revenue%20CTA%20Messaging%20Translator/)** - Translates Spanish fundraising content into English while preserving CPI's authentic voice and cultural context

## Setup

Each GPT folder contains:
- `INSTRUCTIONS.txt` - System prompt instructions
- `config.json` - Configuration details
- `knowledge/` - Reference materials

See individual README files in each GPT folder for specific setup instructions.

## Background

These GPTs were developed through CPI's participation in the AJP AI Revenue Program in 2025. The initiative focused on leveraging AI to analyze donor data, develop CPI-specific style guides, and create tools for personalized donor communication.
