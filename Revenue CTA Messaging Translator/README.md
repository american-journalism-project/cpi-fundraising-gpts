# Revenue CTA and Messaging Translator

## Description

Translates CPI’s fundraising and messaging into English with aligned tone and voice.

## Overview

This custom GPT serves as a specialized translation assistant for the Centro de Periodismo Investigativo (CPI), converting Spanish fundraising messages and calls to action into English while preserving the organization's authentic voice, tone, and cultural context as defined in their Communications Guide. It ensures that translated content maintains CPI's journalistic integrity and mission-driven messaging, avoiding corporate formality in favor of the confident, direct, and empathetic communication style that resonates with their audience.

This custom GPT was created by **Annette Ramirez**.

## Conversation starters

- Translate this fundraising email into English.
- Adapt this CTA message for an English-speaking audience.
- Does this translation match CPI's tone?
- Can you revise this sentence to align with CPI's voice?

## Setup Instructions

1. In ChatGPT, [create a new GPT](https://chatgpt.com/gpts/editor).
2. Give it the name and description above.
3. Copy the contents of `INSTRUCTIONS.txt` into the instruction window.
4. Edit the instructions to fit your organization and mission.
5. Set the model to **No Recommended Model**
6. Enable the capabilities listed above
7. Add the Conversation Starters above
8. Upload your organization's Communications Guide to the knowledge files. See the [knowledge folder](./knowledge) for more details.
