# Knowledge Files

This folder contains the communications guide utilized by Centro de Periodismo Investigativo as a knowledge file to support this GPT.

Rather than using this guide directly, use it as an example and inspiration to create and upload your own.

## Files

- **Communications Guide – Llamados a Donar del Centro de Periodismo Investigativo (CPI).pdf**

## Setup

1. Upload your newsroom's communications guide in the Knowledge section.
2. The GPT will use it as context for responses
