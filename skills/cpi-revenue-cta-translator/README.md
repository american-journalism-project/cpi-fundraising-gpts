# CPI Revenue CTA and Messaging Translator

This skill translates CPI Spanish fundraising and audience-engagement messages into English while following CPI's editorial voice.

## Use the skill

Install the complete `cpi-revenue-cta-translator` folder in an assistant that supports skills. Keep `SKILL.md` at the package root and follow the host's instructions for enabling a skill.

## Provide the communications guide

Use the CPI Communications Guide as the reference for tone, preferred vocabulary, and examples. The guide is in the original GPT materials at [CPI knowledge files](../../Creador%20de%20mensajes%20de%20recaudacion%20de%20fondos%20CPI/knowledge/README.md). Make the guide available to the assistant when using the skill.

## Adapt for another newsroom

Replace CPI's voice and cultural context with the newsroom's approved communications guidance. Keep the skill focused on translating Spanish revenue messaging and calls to action into English with nuance and fidelity. Update examples and vocabulary only from approved materials; do not import CPI facts or style assumptions.
