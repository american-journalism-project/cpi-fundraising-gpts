# CPI Revenue CTA and Messaging Translator

This skill translates CPI Spanish fundraising and audience-engagement messages into English while following CPI's editorial voice.

## Use the skill

Install the complete `cpi-revenue-cta-translator` folder in an assistant that supports skills. Keep `SKILL.md` at the package root and follow the host's instructions for enabling a skill.

## Reference material

The package includes the CPI Communications Guide at `references/communications-guide.pdf`. Use it as the reference for tone, preferred vocabulary, and examples.

## Adapt for another newsroom

Replace CPI's voice and cultural context with the newsroom's approved communications guide. Keep the skill focused on translating Spanish revenue messaging and calls to action into English with nuance and fidelity. Update terminology only from approved materials; do not import CPI facts or style assumptions.
