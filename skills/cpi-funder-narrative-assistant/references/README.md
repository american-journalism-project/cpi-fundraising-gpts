# CPI Funder Narrative Assistant knowledge files

The original GPT setup asks users to compile and provide organization-specific knowledge documents. Examples include a strategic plan, mission statement, past grant applications, impact statements, and partnership pitches.

The [sample image](sample_knowledge_docs.jpg) shows examples of CPI's knowledge files. It is illustrative only. Those underlying documents are not included in this package, so provide the approved materials needed for the task in the skill's host.
