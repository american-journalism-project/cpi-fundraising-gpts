# CPI Funder Narrative Assistant

This skill drafts and tailors CPI grant proposals, cover letters, concept notes, thank-you messages, talking points, and short fundraising copy.

## Use the skill

Install the complete `cpi-funder-narrative-assistant` folder in an assistant that supports skills. Keep `SKILL.md` at the package root and follow the host's instructions for enabling a skill.

## Provide CPI context

The skill needs CPI's approved organizational materials for specific examples and impact claims. The complete CPI knowledge corpus is not included here. Provide relevant materials such as a strategic plan, mission statement, past grant applications, impact statements, or partnership pitches.

## Adapt for another newsroom

Use the CPI version as the starting point. Replace CPI's mission, vision, reporting areas, geography, examples, and cultural guidance with that newsroom's approved information. Update voice and formatting preferences while preserving the workflow for funder tailoring, clarification, and narrative drafting. Never carry CPI facts into another newsroom's materials.
