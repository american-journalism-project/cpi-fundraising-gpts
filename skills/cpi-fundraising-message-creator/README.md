# CPI Fundraising Message Creator

This skill creates and evaluates CPI messages for fundraising campaigns, institutional development, and events.

## Use the skill

Install the complete `cpi-fundraising-message-creator` folder in an assistant that supports skills. Keep `SKILL.md` at the package root and follow the host's instructions for enabling a skill.

## Provide the communications guide

Use the CPI Communications Guide as the reference for tone, voice, institutional approach, and best communication practices. The guide is in the original GPT materials at [CPI knowledge files](../../Creador%20de%20mensajes%20de%20recaudacion%20de%20fondos%20CPI/knowledge/README.md). Make the guide available to the assistant when using the skill.

## Adapt for another newsroom

Replace CPI's mission and values with the newsroom's own, and provide its approved communications guide. Adapt tone and institutional guidance while preserving the skill's core tasks: creating messages and giving clear, specific, constructive feedback on drafts. The skill may request needed context or make reasonable assumptions when context is limited, as long as it follows the supplied guide.
