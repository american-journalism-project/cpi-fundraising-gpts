# CPI Funder Narrative Assistant

## Description

Tailored assistant ready to generate and refine CPI narratives on demand.

## Overview

The CPI Funder Narrative Assistant is a specialized writing tool designed to help Centro de Periodismo Investigativo (CPI) craft compelling grant proposals, cover letters, and fundraising materials that align with specific funder priorities while showcasing CPI's investigative journalism impact. It tailors narratives to highlight CPI's mission of promoting press freedom and government accountability, incorporating concrete examples of their reporting victories, FOIA litigation successes, and community outreach to Puerto Rican diaspora populations.

This custom GPT was created by **Annette Ramirez**.

## Configuration

- **Model:** No Recommended Model

## Features

- 🔍 Web Search
- 🎨 Canvas
- 💻 Code Interpreter & Data Analysis
- 📚 Knowledge Files

## Setup Instructions

1. In ChatGPT, [create a new GPT](https://chatgpt.com/gpts/editor).
2. Give it the name and description above.
3. Copy the contents of `INSTRUCTIONS.txt` into your ChatGPT's system prompt
4. Edit the instructions to fit your organization and mission.
5. Set the model to **No Recommended Model**
6. Enable the capabilities listed above
7. Upload knowledge files that reflect your organization's mission and power your narrative. Examples include: strategic plan, mission statement, past grant applications, impact statements, and partnership pitches.
